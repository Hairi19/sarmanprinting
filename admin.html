System Information

Database:
All employee, job & notification data is stored in Supabase (PostgreSQL) and synced to every device automatically.
Login Accounts:
Email & password are managed in Supabase Dashboard → Authentication → Users. Add the user there with the same email, then assign role & page access here.
First User:
The first account to log in automatically becomes the IT Administrator with full access to every page.
